# Excel导入指南

## 导入流程

1. 使用import_excel工具导入Excel文件，参数为文件完整路径
2. 工具会自动处理多Sheet工作簿，每个Sheet创建一个独立的数据库表
3. 自动处理合并单元格和表头识别
4. 导入完成后返回表名、原始Sheet名、字段列表、数据行数

## 导入前确认

- 导入Excel前，系统会显示文件路径并请求用户确认
- 如果文件路径错误或文件不存在，工具会返回错误信息

## 导入后操作

- 导入完成后，使用list_tables查看数据库中有哪些表和字段
- 根据返回的精确字段名编写SQL查询
- 如果用户提供了多个Excel文件，逐个导入

## 元数据管理

- 每个导入的表都会记录元数据：表名、原始Sheet名、字段列表、数据行数、源文件路径
- 重新导入同一个Excel文件时，会更新已有表的元数据（INSERT OR REPLACE）
- list_tables返回所有表的元数据，LLM根据语义判断哪些表与用户需求相关
